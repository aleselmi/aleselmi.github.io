Equazioni di secondo grado

Equazione di secondo grado completa

ax² + bx + c = 0

con a ≠ 0

Prima di risolvere un'equazione di secondo grado, portiamo tutti i termini al primo membro, riduciamo i termini simili e rendiamo positivo il coefficiente a.

Ricorda

Se il coefficiente a è negativo, possiamo moltiplicare entrambi i membri per −1 senza cambiare le soluzioni.

−x² + 5x − 6 = 0
↓
x² − 5x + 6 = 0

1. Risoluzione mediante scomposizione

Scomponiamo il polinomio utilizzando i prodotti notevoli o altri metodi di scomposizione.

Esempio
x² − 5x + 6 = 0

Cerchiamo due numeri che abbiano somma −5 e prodotto +6. Sono −2 e −3.

(x − 2)(x − 3) = 0
Legge di annullamento del prodotto

Un prodotto è uguale a zero se almeno uno dei suoi fattori è zero.

A · B = 0

se A = 0 oppure B = 0

Poniamo ogni fattore uguale a zero.
x − 2 = 0
x = 2

oppure

x − 3 = 0
x = 3
Soluzioni
x₁ = 2     x₂ = 3

2. Risoluzione mediante formula risolutiva

Possiamo risolvere un'equazione di secondo grado anche utilizzando la formula risolutiva.

ax² + bx + c = 0

con a > 0

x₁,₂ = −b ± √Δ 2a

dove il discriminante è:

Δ = b² − 4ac

Nel nostro esempio

Equazione
x² − 5x + 6 = 0

Individuiamo i coefficienti:

a = 1,   b = −5,   c = 6
Calcoliamo il discriminante.
Δ = (−5)² − 4 · 1 · 6
Δ = 25 − 24 = 1
Applichiamo la formula.
x₁,₂ = 5 ± √1 2
x₁ = 5 − 1 2 = 2
x₂ = 5 + 1 2 = 3
Soluzioni
x₁ = 2     x₂ = 3

Abbiamo ottenuto le stesse soluzioni trovate con il metodo delle scomposizioni.

I tre casi del discriminante

Il discriminante ci permette di capire quante soluzioni reali ha l'equazione. Possiamo interpretarle graficamente come le intersezioni della parabola y = ax² + bx + c con l'asse x.

Nei tre grafici consideriamo a > 0: le parabole hanno tutte concavità verso l'alto.

Δ > 0

Due soluzioni reali distinte

La parabola interseca l'asse x in due punti distinti.

Δ = 0

Una soluzione reale doppia

La parabola è tangente all'asse x nel vertice.

Δ < 0

Nessuna soluzione reale

La parabola non interseca l'asse x.

In conclusione

Le soluzioni reali dell'equazione di secondo grado corrispondono alle ascisse dei punti in cui la parabola incontra l'asse x.
