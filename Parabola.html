Parabola

f(x) = ax² + bx + c

con a ≠ 0. Il segno di a determina la concavità della parabola.

Concavità verso l'alto · a > 0

Esempio: f(x) = 1x² − 2x + 2

Concavità verso il basso · a < 0

Esempio: f(x) = −1x² + 2x + 2

La retta tratteggiata verde è l'asse di simmetria della parabola.

Dominio

La funzione quadratica è definita per qualsiasi numero reale.

D = ℝ

Come si disegna una parabola?

Consideriamo la funzione:

f(x) = x² − 2x + 2

I coefficienti sono: a = 1, b = −2, c = 2.

1. Determiniamo la concavità.

Osserviamo il segno del coefficiente a.

Se a > 0, la parabola è rivolta verso l'alto. Se a < 0, è rivolta verso il basso.

a = 1 > 0

La parabola ha concavità verso l'alto.

2. Calcoliamo le coordinate del vertice: V(xV; yV).

Calcoliamo prima l'ascissa del vertice:

xV = −b 2a
xV = −(−2) 2 · 1 = 1

Calcoliamo poi l'ordinata sostituendo xV nella funzione:

yV = f(xV)
yV = 1² − 2 · 1 + 2 = 1
Vertice
V(1; 1)
3. Troviamo l'asse di simmetria.

L'asse di simmetria è la retta verticale che passa per il vertice.

x = xV

Nel nostro esempio:

x = 1
4. Calcoliamo l'intersezione con l'asse y.

I punti dell'asse y hanno x = 0. Sostituiamo quindi x = 0 nella funzione.

y = 0² − 2 · 0 + 2
y = 2

Otteniamo il punto:

A(0; 2)

In generale, l'intersezione con l'asse y è sempre (0; c).

5. Calcoliamo le intersezioni con l'asse x.

I punti dell'asse x hanno y = 0.

Poniamo quindi la funzione uguale a zero:

ax² + bx + c = 0

Nel nostro esempio:

x² − 2x + 2 = 0

Per trovare le eventuali intersezioni con l'asse x dobbiamo risolvere questa equazione di secondo grado.

6. Disegniamo la parabola.

Sul piano cartesiano riportiamo i punti trovati e tracciamo l'asse di simmetria.

Nel nostro esempio abbiamo:

V(1; 1)
A(0; 2)
Asse di simmetria: x = 1

Possiamo calcolare altri punti, se necessari, sostituendo alcuni valori di x nella funzione.

Disegniamo infine una curva regolare con concavità verso l'alto, rispettando l'asse di simmetria.

Posizione reciproca tra una retta e una parabola

Disegnando una retta e una parabola nello stesso piano cartesiano, possiamo osservare quanti punti hanno in comune.

Secante

La retta incontra la parabola in due punti.

Tangente

La retta incontra la parabola in un solo punto.

Esterna

La retta e la parabola non hanno punti in comune.
